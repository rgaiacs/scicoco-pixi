# It Works on YOUR Machine too thanks to Pixi

This repository is the home for the workshop "It Works on YOUR Machine too thanks to Pixi" ([part 1](https://events.hifis.net/event/3911/contributions/24895/) and [part 2](https://events.hifis.net/event/3911/contributions/24910/)) at [SciCoCo.nrw – Science, Compute, Connect](https://events.hifis.net/event/3911/).

## Description

[Pixi](https://pixi.prefix.dev/) is a fast, modern, reproducible and language agnostic package management tool for users, researchers, and developers that dramatic reduce the chance of hit "it works on my machine" wall.

This interactive and hands-on training session will help participants to learn and apply features provided by Pixi that makes projects safe against the "it works on my machine" problem. Example of the features includes declaration of dependencies and creation / use of command short cuts.

Attendees should bring their own device. Pixi works on Windows, macOS and GNU/Linux. Installation of Pixi will be covered at the begin of the training session. Examples will be provided for projects using Python, R, and C.
